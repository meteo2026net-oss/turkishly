# مواصفة مولّد صور المفردات بالدفعات

## الهدف
إضافة مسار إداري لتوليد صورة مستقلة لكل مفهوم تركي، مع إمكانية تشغيل دفعة من 10 إلى 100 كلمة دون إرسال طلب يدوي لكل كلمة. هذه المواصفة لا تعني أن التوليد أو التخزين السحابي مفعّل الآن.

## القرارات
- الكلمة التركية هي المدخل الأساسي، وترجماتها ترتبط بالسجل نفسه.
- صورة واحدة معتمدة للمفهوم تخدم كل اللغات.
- كل صورة تنتج من مهمة مستقلة وتحفظ كملف مستقل؛ لا نولّد لوحة مجمعة ولا نقصّها.
- لا كتابة أو حروف أو ترجمة أو علامة مائية داخل الصورة.
- صيغة النشر المستهدفة WebP.
- لا تنشر الصورة تلقائياً: تمر بمراجعة بشرية.
- لا تحفظ مفاتيح API أو أسرار التخزين داخل Flutter أو GitHub.

## سير العمل
1. يحدد المشرف مستوى أو تصنيفاً أو مجموعة مفردات بلا صور.
2. يستخرج النظام المفردات التي لا تملك صورة منشورة.
3. يعرض معاينة للدفعة وعدد الصور المتوقع وحدّ التكلفة.
4. ينشئ مهمة مستقلة لكل مفردة مع وصف مبني على معناها.
5. يرسل الخادم المهام إلى موفر توليد الصور (Cloudflare Workers AI كموفر قابل للاستبدال).
6. يحفظ الناتج كملف مستقل في موفر تخزين منفصل.
7. يسجل manifest يحوي المسار والبصمة والأبعاد والحجم والحالة.
8. تعرض لوحة المراجعة الصور؛ يعتمد المشرف الصورة أو يرفضها أو يطلب إعادة توليدها.
9. بعد الاعتماد فقط، يحدّث سجل المفردة بمسار الصورة.

## حالات المهمة
- queued: بانتظار التنفيذ
- generating: قيد التوليد
- generated: تم التوليد ولم تتم المراجعة
- approved: تمت الموافقة
- rejected: مرفوضة
- failed: فشل نهائي بعد المحاولات
- needs-sense-review: المعنى غير محدد ويحتاج مراجعة

## ضوابط التشغيل الأولية
- الدفعة التجريبية: 10 مفردات فقط.
- الحد الأعلى في الواجهة: 100 مهمة في الدفعة، مع تقسيم التنفيذ إلى مجموعات صغيرة.
- التوازي الابتدائي: مهمتان فقط؛ يرفع بعد قياس حدود المزود.
- محاولتان إضافيتان كحد أقصى للأخطاء المؤقتة.
- لا تعاد المهمة إذا كانت صورة معتمدة موجودة، إلا بطلب صريح لإنشاء نسخة جديدة.
- مفتاح idempotency لكل مفردة وإصدار وصف لمنع التكرار.
- إيقاف تلقائي عند بلوغ ميزانية الدفعة أو ظهور أخطاء متتالية.
- تسجيل الاستهلاك الفعلي، وعدم الاعتماد على تقديرات ثابتة للصورة.

## قواعد وصف الصورة
يحدد الوصف المفهوم بدقة، ويطلب صورة فوتوغرافية واقعية بتكوين بسيط وإضاءة طبيعية، دون نص أو حروف أو أرقام أو شعارات أو علامات مائية. لا تكتب الترجمة داخل الصورة.

مثال لكلمة elma:
`Photorealistic educational vocabulary photo of one fresh red apple, isolated on a clean soft neutral background, centered composition, natural soft daylight, crisp realistic details, no text, no letters, no numbers, no logo, no watermark, square image.`

## واجهات الخادم المقترحة
- `POST /admin/image-batches`: إنشاء دفعة من قائمة IDs أو تصنيف.
- `GET /admin/image-batches/{batchId}`: حالة الدفعة والإحصاءات.
- `POST /admin/image-batches/{batchId}/pause`: إيقاف مؤقت.
- `POST /admin/image-batches/{batchId}/resume`: استكمال.
- `POST /admin/image-assets/{assetId}/approve`: اعتماد صورة.
- `POST /admin/image-assets/{assetId}/reject`: رفض صورة.
- `POST /admin/image-assets/{assetId}/regenerate`: إعادة توليد.

جميع المسارات الإدارية تتطلب مصادقة وصلاحية مشرف وتحديد معدل الطلبات.

## فصل المسؤوليات
- Flutter: اختيار الكلمات، عرض التقدم، مراجعة الصور.
- Backend/Worker: المصادقة، إدارة الصفوف، استدعاء نموذج الصور، ضبط الميزانية.
- Image provider: توليد صورة واحدة لكل مهمة.
- Object storage: تخزين الملفات الثنائية؛ يختار منفصلاً.
- Vocabulary catalog: يحفظ الترجمة ومعرّف الصورة ومسارها فقط.

## ما لم يُنفذ بعد
- لا توجد مفاتيح أو حسابات مزود متصلة.
- لا توجد نقطة API منشورة أو عملية توليد عاملة.
- لا يوجد مخزن صور سحابي مهيأ.
- لا توجد صور فعلية جديدة في هذا الفرع.
- يلزم اختبار النموذج المختار وقياس التكلفة والحصة قبل السماح بدفعات كبيرة.
