# Turkishly – ساره تركيي

تطبيق Flutter لتعلّم اللغة التركية للناطقين بالعربية، بمسار تدريجي وفق مستويات CEFR من A1 إلى C2.

## الوظائف الحالية
- فهرس الوحدات والدروس حسب مستويات CEFR.
- دروس تفاعلية واختبارات اختيار من متعدد.
- مفردات مرئية ومتابعة الكلمات المتقنة.
- اختبار شامل وتقييم تشخيصي مبني على محتوى المستوى.
- سجل نتائج التقييم وأفضل نتيجة لكل مستوى.
- حفظ التقدم محلياً مع تصدير واستعادة نسخة احتياطية بإصدار محدد وقائمة مفاتيح مسموح بها، مع رفض الملفات الكبيرة والصيغ غير المدعومة.
- مراجعة الكلمات بالتكرار المتباعد بفواصل زمنية متزايدة.
- سجل للأسئلة التي تحتاج إلى مراجعة.
- تدريب محادثة محلي تفاعلي في عشرة مواقف تغطي A1 إلى C2، من التعارف والشراء والسفر إلى اجتماعات المشاريع والعروض البحثية والتفاوض، مع ترجمة عربية وتصحيح فوري وحفظ النتائج في سجل المتعلم والنسخة الاحتياطية.

> تدريب المحادثة الحالي يعمل محلياً بمحتوى محدد مسبقاً؛ لا يدّعي أنه محادثة صوتية أو مساعد ذكاء اصطناعي مباشر.

## التشغيل
```bash
flutter pub get
flutter run
```

## التحقق
```bash
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test
flutter build web --release --base-href /turkishly/
```

يتم تشغيل التحليل والاختبارات وبناء الويب آلياً عبر GitHub Actions عند فتح Pull Request أو تحديثه. كما ينشئ CI ملفات Android وiOS مؤقتاً بواسطة Flutter tooling لاختبار بناء APK تجريبي وبناء iOS دون توقيع على runners المناسبة؛ هذه الملفات المؤقتة لا تُحفظ في المستودع، ولا تغني عن اعتماد ملفات المنصات واختبارها على أجهزة فعلية قبل الإصدار.
بعد نجاح التحقق، تحفظ GitHub Actions نسخة الويب المبنية كـ artifact باسم `turkishly-web-build` لمدة 14 يوماً؛ يمكن تنزيلها من صفحة تشغيل Workflow دون نشر تلقائي للموقع.
تتضمن نسخة الويب بيان تطبيق (PWA) باللغة العربية واتجاه RTL وبيانات التثبيت على الشاشات الرئيسية، مع أيقونة SVG مرتبطة بالبيان. يتحقق CI من صحة JSON ووجود الأيقونة المشار إليها. لم يُفعّل النشر التلقائي أو التخزين الكامل للعمل دون اتصال، ويجب اختبار التثبيت على المتصفحات والأجهزة المستهدفة قبل اعتباره جاهزاً للإطلاق.

## تنظيم المشروع
- `lib/main.dart`: نقطة تشغيل التطبيق.
- `lib/theme/`: ألوان وثيم التطبيق.
- `lib/models/`: نماذج البيانات.
- `lib/data/`: فهرس المستويات والوحدات ومحتوى الدروس.
- `lib/screens/`: شاشات التعلم والاختبارات والمراجعة والمحادثة.
- `lib/services/learning_progress.dart`: حفظ التقدم والمراجعات والنسخ الاحتياطية محلياً، مع تلخيص موضوعات الأخطاء المتكررة لاقتراح مراجعة موجّهة من سجل المتعلم (قواعد عدّ واضحة وليست تشخيصاً بالذكاء الاصطناعي).
- `test/`: اختبارات سلامة المنهاج والتقدم والتفاعلات.
