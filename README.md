# Turkishly

تطبيق Flutter لتعلّم اللغة التركية للناطقين بالعربية، بمسار تدريجي وفق مستويات CEFR من A1 إلى C2.

## الدفعة التأسيسية
هيكل Flutter، الثيم، نماذج الوحدات والدروس، وفهرس أولي للوحدات وشاشة البداية. ستُضاف الدروس التفصيلية تدريجياً إلى ملفات مستقلة.

## التشغيل
```bash
flutter pub get
flutter run
```

## تنظيم المشروع
- lib/main.dart: نقطة تشغيل التطبيق.
- lib/theme/: ألوان وثيم التطبيق.
- lib/models/: نماذج البيانات.
- lib/data/: فهرس المستويات والوحدات والدروس.
- lib/screens/: شاشات التطبيق.
